## 2026-10-07 — Офлайн-запуск и автосборка dist

Что сделали:
- Добавлен `server.mjs` — zero-dependency статический сервер на встроенных
  модулях Node.js, раздаёт `packages/app/dist` с SPA-фолбэком на `index.html`.
- Добавлены ярлыки запуска в корне репозитория: `start.command` (macOS),
  `start.cmd` (Windows), `start.sh` (Linux) — проверяют наличие `node` в
  PATH и дают понятное сообщение, если его нет.
- В репозиторий закоммичена готовая сборка (`packages/app/dist`), чтобы
  скачанный архивом репозиторий запускался без `pnpm install`/`pnpm build`
  и без интернета вообще (кроме AI-функций и GitHub Open/Save — это внешние
  сервисы).
- Сервер слушает фиксированный порт (`47890`) вместо случайного — иначе
  каждый перезапуск на одной машине получал новый origin и, соответственно,
  пустые IndexedDB/service-worker кеш (терялись сохранённые страницы).
- Добавлен GitHub Action `rebuild-dist.yml` — пересобирает и коммитит
  `packages/app/dist` при каждом push в `main`, с защитой от цикла
  (`[skip ci]`, пропуск коммитов от самого бота, `paths-ignore` на сам dist).
- Исправлена скрытая проблема в `vite.config.ts`: путь к ассетам раньше
  зависел от флага `GITHUB_ACTIONS`, а в CI теперь крутятся два воркфлоу
  (деплой на GitHub Pages и пересборка dist) с разными нужными base-path —
  заменено на явную переменную `EDITH_BASE_PATH`.
- Обновлён `README.md`: инструкции по офлайн-запуску и отдельный раздел про
  работу с сетевого диска на разных машинах (сохранённые страницы — это
  память браузера конкретного компьютера, не файлы на диске).
- Удалены случайно загруженные через GitHub web UI файлы-дубликаты
  (`download`, `prettierrc.json`), не несущие смысла.

## 2026-09-25 — MVP: редактор, превью, Ask Edith, PWA

Партия из полутора десятков точечных коммитов (загружены через GitHub web
UI), в сумме — основной функционал первой рабочей версии:

- Синтаксическая подсветка и темы в Monaco (`monacoThemes.ts`), языковые
  настройки редактора.
- Создание нового файла по шаблону (`newFile.ts`) для кнопки Blank Page.
- Панель «Ask Edith» (AI-ассистент) и её стили.
- PWA: `UpdatePrompt` — уведомление об обновлении service worker.
- `DeviceSwitcher`, `ThemeSwitcher`, `ZoomControls`, `ProblemsIndicator`,
  `Icon` — элементы интерфейса панели инструментов превью/редактора.
- Крупный рефакторинг `AppShell` (раскладка панелей) и `index.css`
  (глобальные стили, темизация).
- Правки `editorStore`, `App.tsx`, `main.tsx`, конфигурации Vite/package.json.
- Удалён неиспользуемый `DeviceSwitcher.module.css`.

_(Исходные формулировки коммитов этой партии — обобщённые "Add files via
upload"; что именно менялось в каждом — восстановлено по диффам задним
числом, без привязки к первоначальной причине.)_

## 2026-09-20 — Раскладка панелей, Open folder, автосохранение + фиксы ревью

- Добавлены раскладка панелей Code/Preview с `Swap`, подсветка выбранного
  элемента, едущая со скроллом превью, кнопка **Open folder** (с drag-and-drop
  папки/HTML), статус автосохранения Saving/Saved.
- Правка: коллапс `flex-grow` при Swap — перенесено на инлайн-стили,
  привязанные к позиции в DOM, а не к CSS-классам, зависящим от типа контента.
- Правка: неотфильтрованный рекурсивный обход при импорте папки — добавлены
  список исключений, ограничение на число файлов, различие между "пользователь
  отменил" и "HTML не найден".
- Правка: `CodePane`/`PreviewPane` полностью перемонтировались при каждом
  Swap (из-за скачка `buildVersion`) — обе панели теперь всегда рендерятся
  в одной точке JSX, видимый порядок меняется через CSS `order`.
- Добавлены CSS hot-patch (обновление стилей превью без перезагрузки),
  восстановление позиции скролла при обновлении превью, защита от обработки
  внутренних ссылок как переходов на новую страницу.

## 2026-08-19 — Первый коммит: основа проекта

- Монорепо на pnpm workspaces: `packages/core`, `packages/ai`, `packages/app`.
- Базовый `Vite + React` каркас приложения, Monaco-редактор, превью в
  `<iframe sandbox>`, стартовый экран-лаунчер.
- `packages/ai` — клиент для Ask Edith (Groq/OpenRouter).
- Воркфлоу `deploy.yml` — деплой на GitHub Pages.
- Базовые конфиги: ESLint, Prettier, `.gitignore`, `package.json`.
