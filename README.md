# Edith

Локальный редактор статических HTML-страниц: Monaco + живое превью, без облака.

## Запуск оффлайн / из скачанного архива

1. Скачайте репозиторий архивом (GitHub → Code → Download ZIP) и распакуйте в любую папку.
2. Запустите ярлык в корне: **`start.command`** (macOS), **`start.cmd`** (Windows) или **`start.sh`** (Linux).

Ярлык поднимает локальный сервер и открывает Edith в браузере. В репозитории уже лежит собранная версия (`packages/app/dist`), так что для запуска не нужны ни интернет, ни `pnpm install` — только установленный [Node.js](https://nodejs.org). После первой загрузки страницы приложение — PWA и продолжает работать даже в полном оффлайне (service worker кеширует всё необходимое).

Ask Edith (GPT через Groq/OpenRouter) и GitHub Open/Save всё равно нужен интернет — это внешние сервисы, локально их не обойти.

Если меняли исходники и хотите обновить собранную версию в `packages/app/dist`, пересоберите (`pnpm build`) — при каждом push в `main` GitHub Action сам пересобирает и коммитит `dist`, так что для push через git дополнительных шагов не нужно.

### Сеть/сетевой диск, разные машины

Папку можно держать на сетевом диске и открывать ярлык с разных компьютеров — сам Edith (`server.mjs`) каждый раз запускается **локально** на той машине, с которой его открыли, и только читает файлы с диска; одновременный запуск с нескольких машин безопасен.

Важно: **сохранённые страницы, автосохранение и офлайн-кеш — это память браузера конкретного компьютера** (IndexedDB + service worker), а не что-то, что лежит в папке на диске. На новой машине это будет чистый Edith без ваших старых страниц — перенести их можно только явно: Export/Save on disk, или через GitHub Save/Open (туда тоже нужен интернет). Сервер слушает фиксированный порт, так что повторный запуск **на одной и той же машине** открывает именно те страницы, что сохранили раньше — но между разными машинами это не синхронизируется.

## Разработка

```bash
pnpm install
pnpm dev
```

Откроется Vite-приложение `@edith/app`.

## Что умеет эта сборка

- Код и превью **слева/справа или сверху/снизу** (`Layout`). **Swap ⇄** меняет панели местами. Разделитель тянется; двойной клик — 50/50.
- Подсветка элемента в превью **едет со скроллом** и скрывается, когда узел уходит из кадра.
- **Open folder** и drag-and-drop папки/HTML на лаунчер — подхватываются соседние CSS/JS/картинки.
- Autosave в IndexedDB со статусом Saving/Saved.
- Ask Edith, GitHub Open/Save, экспорт ZIP — как раньше.

## Горячие клавиши

- `Ctrl/Cmd+S` — сохранить
- `Ctrl/Cmd+Enter` — обновить превью
- `Ctrl/Cmd+F` / `H` — поиск / замена в редакторе
- `Esc` — выйти из полноэкранного превью
